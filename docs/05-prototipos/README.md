# Protótipo inicial

O protótipo navegável está em [frontend](../../frontend/README.md), com roteiro de demonstração e limitações em [DECISOES.md](../../frontend/DECISOES.md). É uma entrega de interface com dados sintéticos, não o sistema definitivo.

A entrega cobre pedidos com vários produtos, OP automática e manual, necessidades, compras/recebimento, estoques, produção, expedição, custos e usuários internos. O kanban detalha acompanhamento por produto sem produção parcial. Cadastro de receitas, preservação da composição, recebimentos parciais, autenticação real e concorrência exigem evolução conforme as decisões documentadas.

Para avaliação, usar os cenários da [metodologia](../06-testes/metodologia-de-validacao.md), distinguindo o que o protótipo demonstra do que depende de backend. A entrega do protótipo está concluída como material inicial; avaliação pelo grupo e implementação definitiva permanecem atividades distintas.
