# Gestão Integrada de Estoque e Produção no Setor Alimentício

Sistema para pequenas empresas do setor alimentício, baseado na integração entre receitas, necessidades de insumos, compras, produção, estoque e expedição.

## Objetivo
Desenvolver um sistema integrado para gestão de estoque e produção, relacionando insumos, receitas, compras, ordens de produção, produtos acabados e expedição.

## Funcionalidades previstas
- Cadastro de produtos, insumos, receitas, fornecedores e clientes.
- Controle de estoque de insumos e produtos acabados.
- Registro e acompanhamento de compras.
- Gestão de ordens de produção.
- Controle de expedição.
- Registro simplificado de movimentações financeiras.
